# dsh-desktop — DeepSeek Harness 桌面客户端

[English](README.md) | 中文

Tauri 2 桌面壳：在原生窗口里内嵌 dsh web UI，内置 Node 运行时与裁剪后的 dsh 发行，开箱即用、关窗不退出（托盘常驻）、服务崩溃自动重启。**不修改任何上游 `packages/` / `apps/cli` 代码**，四个 agent preset（`standard` / `code` / `minimal` / `cordis`）由上游原样提供。

## 架构

```
src-tauri/            Rust shell
  src/dsh_runner.rs   dsh child-process lifecycle: spawn `dsh web --port 3081 --no-open`, port health probe, crash auto-restart (does not race when dsh-plugin restarts itself)
  src/tray.rs         tray residency: closing the window hides it; only tray Quit ends the process tree
  src/setup.rs        first-run wizard commands: write preset into the profile patch (agent-presets.config.default), install plugins (dsh plugin / local copy)
ui/dist/              shell frontend (pure static, no build): index.html full-window iframe + error banner; wizard.html first-run wizard
scripts/bundle-runtime.mjs  pack Node runtime + pnpm-deployed dsh closure + local plugins → runtime/
scripts/generate-mac-icons.mjs  rewrite src-tauri/icons/icon.icns from the tile master onto Apple's 824/1024 icon grid (see the script header)
runtime/              packaging output (not committed; generated by CI; tauri.conf.json maps it as bundle resources)
```

图标：提交的瓷砖母图（`src-tauri/icons/official-512.png`）构图满幅，适配 Windows `icon.ico`，但会让 macOS Dock 把应用渲染得比系统图标大 ~25%。`icon.icns` 以重生成后的形态提交（`node scripts/generate-mac-icons.mjs`，Apple 网格留白 + 圆角）；`.ico` 与 PNG 家族保持 Windows 形态不动。

端口约定：壳启动 `dsh web --port 3081 --no-open`，端口被外部进程占用时从 3082 起扫描，并捕获 dsh 打印的一次性认证 URL。`authenticate_webview` 先通过本机 HTTP 完成 token 交换（同时是存活探测，失败先于 iframe 401），再按 webview 引擎分流：Windows 上把签名的浏览器 cookie 安装进原生 WebView cookie 存储（`SameSite=None; Secure`，跨源 iframe 必需），返回 iframe 加载的干净 URL；WebKit 系（macOS/Linux）直接返回带 token 的 URL，因为壳预装的 cookie 到不了那个 iframe——WebKit 不向纯 HTTP 的 loopback 发送 `Secure` cookie，也不把第三方 iframe 的存储交出来，这正是 mac 每次启动撞出 401 文案的原因，所以 iframe 自行加载 `/?token=…`，在服务端 303 跳转里拿到它自己的 `HttpOnly; SameSite=Strict` cookie，后续请求全部同源。`dsh://ready` 负载为 `{ url }`，`dsh_status` 返回 `{ running, port, url }`。CLI 用户的 `dsh web` 默认 3080 不受影响。`/api`（含 `host.openPath`、WebSocket 下行、SSE）全部由 dsh 自身提供，壳不做反向代理。壳不渲染顶部导航栏，界面完全由 dsh UI 自身提供；壳与 iframe 之间只走宿主桥（`source: 'dsh-desktop-host'` 的通知与外部链接消息）。

## 开发

前置：Node ≥ 22.19、pnpm ≥ 11、Rust ≥ 1.77、Tauri CLI（随本包 devDependency 提供）。

```sh
pnpm install                # workspace dependencies
pnpm run build              # produce lib and apps/web/dist (static frontend for dsh web)
pnpm tauri dev              # from apps/desktop-tauri; dev mode uses PATH node + apps/cli/lib/bin.js
```

dev 模式需要已构建的 CLI 产物（`pnpm run build`）；也可用环境变量覆盖运行时解析：
`DSH_DESKTOP_NODE`（node 可执行）、`DSH_DESKTOP_DSH_BIN`（dsh CLI 入口）、`DSH_DESKTOP_PLUGINS_DIR`（本地插件目录）。

## 构建发行版

```sh
pnpm run build              # repository artifacts
node scripts/bundle-runtime.mjs --platform win   # win|mac|linux; generates runtime/
pnpm tauri build            # package installers (runtime/ is bundled as resources)
```

CI（`.github/workflows/desktop-release.yml`）在三平台矩阵上执行同一流程并上传 GitHub Release；打 `v*` tag 或手动触发。

## 首次启动

- 默认预设：`standard`（可改 `code` / `minimal` / `cordis`，写入 `~/.dsh/profiles/web/cordis.patch.yml` 的 `agent-presets.config.default`）
- 默认插件：`dsh-plugin`（插件中心/市场）、`dsh-win-terminal-inspector`（仅 Windows，本地复制 + patch insert）
- 可选插件：`dsh-better-sidebar`、`dsh-notification`、`dsh-session-context-menu`、`@xmanrui/dsh-im`（企微/飞书/钉钉/微信/QQ 等 9 渠道）、`dsh-lark`、`dsh-qqbot`、`dsh-vision-router`、`graph-memory`、`aegis`

插件安装/更新/卸载全部走 dsh 官方机制（`dsh plugin` / dsh-plugin 插件中心），运行时内置 pnpm 与其同版本族。
