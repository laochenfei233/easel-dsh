# 对标量化指标与交付规范

## 指标定义

| 指标 | 定义 | 来源 |
|---|---|---|
| 粉丝 / 关注 / 获赞与收藏 | 主页显示值 | 登录态 SSR，精确值 |
| 笔记数 | `posted` | SSR |
| 累计获赞 / 收藏 | `liked` / `collected` | SSR |
| **单篇均赞** | **`liked ÷ posted`** | 派生 |
| 命中关键词数 | 多关键词 sweep 中该账号作为笔记作者出现的词数 | sweep 派生 |

**单篇均赞是核心效率指标。** 它把「发了多少」和「拿到了多少」压成一个数，
用来识别「高产低效」账号 —— 粉丝量级和笔记总数都会骗人，均赞不会。

## 量级落差的处理（关键）

同赛道账号的单篇均赞可以差 **两个数量级**（实测样本 11.8 ~ 2,288，差 194 倍）。
画图时必须显式处理刻度：

- **线性刻度**：只在**想强调 dominance** 时用（如「主号占矩阵粉丝 94.3%」）。
  代价是小值被压成贴地的细条 —— 此时**必须在每根柱上标真实值**，
  否则图不可读；并在图例里说明「线性刻度下近几贴地」。
- **对数刻度**：当需要**同时比较多个量级**时用。必须：
  1. 在标题旁标注「对数刻度」
  2. 柱顶仍标真实值（不是对数值）
  3. 图例里写清为什么用对数（「差距 N 倍，线性刻度下会被压成一条线」）
- 两种刻度不要在同一张图里混用，也不要在相邻图之间悄悄换刻度而不标注。

## 对比结论的表述纪律

- 用**倍数**和**占比**代替形容词：「低 7.3 倍」「只有对方的 23%」，而不是「明显偏低」。
- **给出最干净的对照**：优先选粉丝量级相近、内容形态相同的账号做一对一比较，
  比一堆平均值有说服力。
- 粉丝量级高不等于效率高。**必须同时给出粉丝数、笔记数与均赞**，
  只报粉丝会得出相反结论。
- 差异要归因到**内容形态**（哪类内容进流量池、哪类不进），不要停在「互动低」。

## 交付物规范

三种形态，同一份数据：

| 交付物 | 用途 | 关键参数 |
|---|---|---|
| **大屏 HTML** | 桌面看、可交付客户 | 自包含单文件、无外部依赖、离线可开 |
| **手机版 PDF** | 转发、存档 | `paperWidth = 手机宽度/96` 英寸，`printBackground: true` |
| **长图 PNG** | 社媒/IM 直接发 | 视口宽 420 CSS px，`deviceScaleFactor = 3`，切片拼接 |

设计语言（飞书风格参考，可按品牌替换）：

- 主色 `#3370FF`；语义色 绿 `#34C724` / 红 `#F54A45` / 橙 `#FF8800` / 紫 `#7F3BF5`
- 深色渐变页头 + 白卡片 + 圆角 10px + 弱阴影
- KPI 磁贴（大数字 + 变化标签）+ 明细表 + 彩色柱形图 + 结论块
- **本号所在行/柱必须视觉高亮**（底色 + 描边），否则读者找不到对照点

## 图表导出核对清单

导出后必须自查，不能假设渲染正确：

1. 柱高是否与数值成比例（**对数图尤其要核对**：最高柱应触顶）
2. 数值标签是否被容器裁掉（最高柱上方要预留 `padding-top`）
3. 超长图是否有空白断层（可编程检测连续空白行）
4. 字体是否原生高 DPI 渲染（**1:1 裁一块看边缘**，不要只看缩略图）
5. PDF 是否逐页可读、表头跨页是否重复、有无整页空白
